Student Information Management System

A modern, user-friendly frontend web application designed to organize student records. It provides a simple way to register, find, and manage student information.

Project Objectives

  • Organize student details in one place.
  • Make student records easier to search.
  • Provide registration validation.
  • Demonstrate responsive web development.

Main Features

  • Student registration.
  • Search, filtering, and sorting.
  • Edit and delete student records.
  • Browser localStorage.
  • Responsive Bootstrap design.

Technologies Used

HTML5 CSS3 JavaScript Bootstrap 5 localStorage

Project Scope: This is a frontend demonstration. It does not use a server, database, or real authentication. Records are stored only in the browser.
