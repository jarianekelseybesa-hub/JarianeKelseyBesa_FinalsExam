
# PROMPT ENGINEERING LOG

## Entry 1: Project Planning

### Technique or Framework
Role Prompting and Context Prompting

### Purpose
To plan a Student Information Management System
that follows the CC211 examination requirements.

### Exact Prompt
Act as a web development tutor. Help me plan a
Student Information Management System for my CC211
finals laboratory exam.

The application must use HTML, CSS, JavaScript,
and Bootstrap. It must be frontend only.

Include a dashboard, registration page, management
page, and about page.

### Result Summary
The AI generated a project plan with four pages
and a proposed folder structure.

### Evaluation
The proposed project matches the frontend-only
requirement and includes the requested pages.

### Improvement
Keep the features manageable and ensure that
student records are saved using localStorage.
