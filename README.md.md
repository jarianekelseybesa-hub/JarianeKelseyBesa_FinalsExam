
# Student Information Management System (SIMS)

## Project Description

SIMS is a responsive frontend web application designed
to organize and manage student information.

Users can register students, search records, filter
students, edit information, and delete records.

The system uses browser localStorage to save student data.

## Problem Being Addressed

Student information can become difficult to organize
when records are stored in separate lists.

SIMS provides a simple centralized interface for
recording and finding student information.

## Target Users

- School staff
- Student assistants
- Students
- Instructors

## Project Objectives

1. Organize student information.
2. Make student records easier to search.
3. Provide student registration.
4. Demonstrate responsive web design.
5. Demonstrate JavaScript and localStorage.

## How to Run

1. Download the project.
2. Extract the ZIP file.
3. Open the folder in Visual Studio Code.
4. Open index.html using Live Server.
5. Navigate through the website.

## Testing

Perform the following tests:

- Check navigation links.
- Register a student.
- Test empty form submission.
- Test invalid email addresses.
- Test duplicate student IDs.
- Search for student records.
- Filter students by course.
- Sort student records.
- Edit student information.
- Delete student records.
- Refresh the browser and check localStorage.
- Test mobile responsiveness.

## Known Limitations

- Frontend demonstration only.
- No online database.
- No real authentication.
- Records are stored in the current browser.
- Clearing browser storage removes saved records.
